Sou dev full stack há mais de 7 anos, com o backend em **.NET** como casa e **Node.js** e **Python** do lado. Passei por times remotos construindo microsserviços orientados a eventos com RabbitMQ e Redis, modernizando sistemas legados (.NET Framework → .NET 6+, Angular 8 → 18) e cortando tempo de resposta de API em 80%.

Hoje toco o **Protokol** e um punhado de produtos próprios, do app nativo de Windows ao SaaS multi-tenant, e escrevo sobre as decisões de arquitetura por trás deles em [racoelho.com.br](https://racoelho.com.br).
